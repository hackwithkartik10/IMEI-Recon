# IMEI Inspector

📱 A Python-based IMEI lookup tool that identifies mobile device brand and model information from IMEI numbers.

## Features

- Lookup device information using IMEI numbers
- Identify device brand and model
- Fast and lightweight
- Simple command-line interface
- Easy to customize and extend

## Installation

```bash
git clone https://github.com/hackwithkartik10/IMEI-Recon.git
cd IMEI_Recon
```

## Usage

```bash
python3  imei.py
```

Enter an IMEI number when prompted.

Example:

```text
Enter IMEI: 356789123456789

Brand: Example Galaxy
Model: Example SamsungA20
```
